# Multi-Agent Warehouse Robot Coordinator

## Foundations of Artificial Intelligence Case Study

A multi-agent warehouse simulation in which autonomous robot agents coordinate with a central coordinator agent to perform package transportation efficiently.

## Project Status

🚧 Development in progress

## Planned Features

- Multi-agent warehouse environment
- Autonomous robot agents
- Coordinator agent
- Dynamic task allocation
- A* path planning
- Obstacle avoidance
- Conflict resolution
- Dynamic path replanning
- Robot failure and task reassignment
- Pygame-based simulation
- Performance evaluation
